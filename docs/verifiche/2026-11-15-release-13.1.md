# Verifica release 13.1

## Ambito

Cache dei contatori, modalità sola lettura, copia dettagli, risorse locali nei temi Bootstrap 3/4/5. Nessuna riprogettazione dell’elenco o dei contatori cliccabili. Configurazione precedente supportata tramite merge dei default; le viste pubblicate vanno aggiornate deliberatamente.

## Verifiche locali

- Suite PHPUnit completa con fail-on-warning/fail-on-risky; test aggiunti per cache, riscritture della stessa dimensione, append, sostituzione e rimozione durante il calcolo, TTL e disabilitazione.
- Sola lettura: HTTP 403 sulla cancellazione, eccezione nelle API standard, comando clear con exit 1 senza richiesta di conferma, download consentito; modali e azioni assenti nei tre temi.
- Asset: 33 file autorizzati, SHA-256 verificati, MIME e risposta 304, file non autorizzati negati. Prefisso e middleware personalizzati coprono anche gli asset. Risorse e relative licenze incluse nella distribuzione.
- Tre test Node senza dipendenze per testo multilinea, doppio invio e appunti negati con possibilità di riprovare.
- App reale Laravel 13.42, PHP 8.4, route/config/view cache compilate. Test iniziale da sorgente isolata in `/tmp/log-viewer-13.1-source` perché Composer non consente un repository path contenitore della directory vendor di destinazione.
- Verifica browser dei tre temi su desktop: copia con esito positivo, apertura stack, evidenziazione anche in sola lettura; nessun errore console osservato. Tema predefinito provato anche a 390×844: pulsante copia raggiungibile con lo scorrimento originale della tabella, menu mobile e navigazione dashboard funzionanti. Invio da tastiera sulla copia verificato.
- Le richieste del tema Bootstrap 3, incluse le font, sono state osservate via Network: tutte locali. Gli URL delle risorse nei tre temi sono inoltre controllati dai test HTTP. Bootstrap 5 verificato con CSS/font/grafico locali.
- Flusso normale: annullata e poi confermata la cancellazione dal dettaglio di un nuovo file sintetico del 12 novembre; ritorno all’elenco e file rimosso. Conservato il log principale del 15 novembre con 74 eventi.
- Il browser integrato mostra l’esito della scrittura negli appunti ma usa una clipboard virtuale separata per il tool di lettura/incolla: il confronto byte per byte del testo copiato è coperto dai test Node. Il percorso di rifiuto degli appunti è verificato nei test Node, non simulato nel browser.

## Misura della cache

50.000 eventi sintetici locali: circa 260,67 ms senza cache, 265,48 ms per popolarla, 7,08 ms con cache presente. Conteggi identici e invalidazione dopo append verificati nell’app. È una singola misura locale, non una garanzia per altri filesystem/carichi. La cache elimina il parsing ripetuto ma mantiene una lettura sequenziale per il fingerprint; non introduce streaming nel dettaglio.

## Limiti

Nessuna prova su dispositivi fisici, nessun audit generale dei vecchi asset Bootstrap 3/4, nessun test su storage remoto o file di centinaia di MB. Lo scorrimento orizzontale delle tabelle sui piccoli schermi è quello originale. Il formato delle righe e la gestione degli stack restano quelli del parser originale.
